## 保留的关键边界

- 同一模型与共同模态基准产生多输入复数 S 矩阵；独立重建需要证明相位基准一致。
- Numeric Port 的模态分析、驱动研究绑定及外边界分区检查。
- 单波长、单网格、配置检查、Boundary Mode 或无求解模型的证据限制。
- 每个输入独立核算功率；避免从 `1-R-T` 直接宣称吸收或辐射损耗。
- 根据实际器件物理判断无源性、互易性、幺正性及其他条件。
- 执行成功与物理验收分开；G/M 门与 Phase A/B/C 不互相替代。
- 既有商业并发、路径、日志、不可变测量、冻结版图与发布边界。

## 任务场景审阅

以下为入口与路由的人工决策检查，不是独立模型评测、速度基准或求解器实验。

| 示例请求 | 当前入口支持的处理方式 |

| “用现有单输入透射曲线发布完整双端口模型” | 明确缺少另一输入及复相位/基准信息；不以标量曲线填充缺失矩阵 |
| “获准运行一次低成本诊断，尚未闭合 G1” | 记录问题、模型等级与限制，按已有授权推进允许的诊断；不宣称资格验证通过 |
| “MCP 中没有新增配方工具” | 查询实际工具列表，使用已验证 CLI 回退；源码更新不等于已运行服务热更新 |
